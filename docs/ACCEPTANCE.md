# 首版验收

## 内容

- 16 个源短章、10 位讲者、13 个术语的知识覆盖可追溯；不机械要求卡片数与源条目数相同。
- 25 个来源 ID 均有记录；前台卡片引用无悬空 ID。内部资料缺口不渲染成首屏提示墙。
- 日程 15 个区块完整；28 日开幕演讲包含两个讲题，保留共同时间段。
- 保留官方原题与必要外文；翻译提示不伪装为正式中译。
- 卡片主文具备真正知识，不是每卡都只给“听会建议”。

## 行为

- 上下滑动、返回上一张、桌面按钮/键盘可用；打开详情、关闭详情后仍停在原卡。
- 分类、搜索、讲者/场次跳转和收藏过滤能正确往返。
- 刷新保留位置、收藏、笔记；存储失败可提示但不阻断阅读。
- 导出/导入可往返；无效 JSON、不支持版本、错误字段不会静默覆盖用户数据。
- 日程用 Asia/Shanghai；以大会前、10/29 换场、10/31 结束后三类时间做测试。

## 离线

在线首次完整加载 → 确认缓存完成 → 断网 → 关闭并重新打开/刷新 → 刷卡、查日程、收藏与记笔记。记录实际浏览器和测试条件。外部来源打不开只影响外链，不影响正文。

部署到子路径时资源与 Service Worker 路径正确；新版本可更新，不让旧缓存永久锁住旧日程。无网络依赖的核心字体、图标和正文要实际核查。

## 布局和可访问性

程序化检查 320/375/390/430 像素宽度、横屏及大字号下的溢出与可操作性；没有因为固定一屏而把正文裁掉。支持减少动画与键盘导航，焦点可见，详情开关不丢焦点。

本地 Codex 不做截图/读图/图片视觉验收。用户提供真实手机截图，交 ChatGPT 审阅；iPhone Safari 与微信内置浏览器是否实测必须分别说明。

## 工程交付

干净构建；可复现依赖；数据验证脚本或测试；必要交互测试；README 启动/构建/部署步骤；真实结果写入 `docs/IMPLEMENTATION_STATUS.md`；提交 SHA。未运行的测试写未运行，不以推断代替通过。
