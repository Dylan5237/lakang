### 离线测试条件

Edge 持久化用户目录 + 子路径 `/lakang/` 静态服务：联网首访并等到“离线已就绪” → 关闭浏览器 → 关闭静态服务器（真实无网络）→ 重启浏览器冷启动，卡片 K001、日程总览 15 项、详情页出处仍可读。缓存更新：改动 `sw.js` 字节模拟新版本，出现“有新版本可用”，点更新后接管并重载。

注意：首个 Service Worker 尚在激活时就触发更新（人为制造的时序），更新条不会立即消失；第二次打开后的真实场景测试通过。

### 小屏卡片高度发现

标准字号下比视口高的卡片数量（70 卡实测）：320×640 为 64/70，375×667 为 48/70，390×844 与 430×932 为 0；横屏 667×375 为 70/70、844×390 为 69/70；字号 145% 时大多数卡更高。因此操作栏做成底部粘性、横屏隐藏阶段标签，卡片内容经同一滚动容器读完。

## 构建与部署

```bash
npm ci
npm run dev        # 开发
npm run build      # 产出 dist/
npm run preview    # 本地预览
```

把 `dist/` 全部发布到任意静态托管（域名根或子路径均可：`base: './'` + hash 路由）。需 HTTPS 才启用 Service Worker；`sw.js` 不要强缓存。详见 README。

## 已知限制 / 后续

- 日程状态按设备当前时间 + Asia/Shanghai 绝对时刻判断；设备时钟错误会导致“进行中”提示错误。
- 本地数据（收藏/笔记/位置）只在浏览器 localStorage，清理浏览器数据或更换设备会丢失，需用“我的”页导出备份。
- 搜索为本地子串匹配，没有分词与拼音。
