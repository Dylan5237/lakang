# 知识卡编辑规范

## 核心原则

读者需要知识，不需要持续观看编辑自证。质量来自内容本身的准确、具体、可理解与有出处，而不是在每张卡上反复写“真实性”“核验范围”“仅供参考”。

原手册中的“边界与缺口”“未取得全文”等记录作为内部编辑依据保留，不机械搬到主视图。该记录限制了能写什么；隐藏说明不等于允许扩大主张。

## 一张卡应完成的事

1. 一个明确问题。标题不能只写“身体”“拉康”这类目录词，也不要用“99%的人不知道”一类噱头。
2. 一个真实知识点。解释关键关系，而不是只提醒读者“留意”“关注”“想一想”。
3. 一处帮助理解的支撑：必要的区分、原文位置、历史节点、具体作品，或明确标记为虚构的例子。
4. 一句带得走的话，或一个自然通向大会的问题。不是所有卡都需要提问。

主文可先以约 120—220 个汉字为编辑目标，非强制字数。复杂概念拆成有承接关系的多卡，详情可展开；不要为适配屏幕删掉决定结论的条件。

建议数据结构：id、topic、title、body、takeaway、detail、sourceIds、sessionIds、speakerIds、relatedCardIds。字段可按工程调整，但 ID 和引用必须可校验。

## 事实和理论的写法

- 理论立场写出归属，如“在拉康这一论述中”“大会会引把……”。不要将学派概念写成已证实的普遍生物机制。
- 研究结果保留对象、设计、时长与关键结果；量表结果不一致时不能只留下阳性结果。
- “枸杞多糖”研究不改写成“枸杞糖肽”研究，更不转成“吃枸杞能治疗抑郁”。本届题目与既往制剂的关系尚待讲者说明。
- “享乐”不是开心或自愿受苦；“症状有功能”不等于应该维持痛苦。
- “检查暂未解释”不等于心理原因已成立；身体痛苦本身不因解释未明而失真。
- 三界是关联中的理论概念，不是给读者自行诊断的三只分类筐。
- “并入”不直接等同内摄、内化或认同；la Chose 不直接等同日常物品或其他对象术语。
- 现场片段不单独证明长期疗效。临床保密集中放在合适的知识卡或工具处，不在每一张概念卡重复。

## 历史与人物的写法

- 本届正式名为第一届大湾区大会，不把广州往届顺延为本届届次。
- 2016-09-19 是合作协议节点，不是已经核实的第一届大会举办日期。
- 第五届《幻想与妄想》的年份未明确，不放入确定年份时间线。
- 区分著作、共同主编、合译、论文、公开演讲和研究成果。
- Luc Faucher 要以圣安娜医院的临床身份匹配，不归入同名加拿大哲学学者的论文。
- 有书目或目录只能写书目、章节及可支持的关联；不能扩写为全书理论综述。
- 高杰尚无完整可归属著作目录，不补造代表作。相同姓名不是作者同一性的证据。
- 27 日晚间讲题、各场临床演示个案和具体形式未公布，不编造预告。

## 风格示例

不采用："本卡来源真实性已核验；仅供会前参考，不代表讲者将讲述以下内容。"

采用："在本届会引中，身体不只指器官的集合，还涉及一个人如何被命名、如何感受并对待自己的身体。听见同一个‘身体’，先分清讲者在回答哪一层问题。"

不采用："十川幸司提出节奏能够重建心理空间并治疗某类患者。"（资料不支持这种展开。）

采用："十川幸司 2019 年的《フロイディアン・ステップ》把‘节奏与心理空间’放在第七章第二节。预读可从这一节切入，带着‘节奏怎样联系心理空间’听本届晚间演讲。"

## 发布前检查

每条事实可追到来源；每个推论不过度包装成讲者结论；例子不冒充真实个案；具体研究条件没被省略；没有大段复制受版权保护全文；公众正文没有私人称呼；书目链接可查但不抢主阅读；卡片不是长文的随机切片。
