## 原始PDF状态与导入

```sh
python scripts/import_official_originals.py /path/to/wx-pdf-20261026.zip
python scripts/import_official_originals.py /path/to/wx-pdf-20261026.zip --apply
python scripts/validate_materials.py
npm run build
```

工具校验四个精确文件名和SHA-256，再写入public/originals及注册表；同文件重复执行不重写，不覆盖不同内容，不展开任意ZIP路径。已在工作容器用真实ZIP测试预览、导入、重复导入、冲突拒绝与符号链接拒绝。PDF合计14,001,827字节，未预缓存这批大文件；可在线查看／保存，文字版随站点离线缓存。授权发布范围仍以用户与主办方的实际授权为准。
