# 本站原创教学例子与学习工具

2026-10-26。本文件是来源 S38 的实际内容，不是外部研究、会议正式规定或临床操作指南。

## 用途

帮助读者把理论概念、实际观察与自己的推论分开。情境例子由编者创作，不来自真实患者、讲者病例或读者的个人资料。

## 原创例子

- K004：进入教室时胃部不适，用于区分医学了解、感受描述与情境。
- K014：‘想离开……这个岗位’的自我修正，用于区分原话与听者追加的解释。
- K042：家长、青少年、学校与专业人员的不同说法，用于区分求助目标与经验。
- K045：写信与排列同一名字的比较，用于区分内容、形式、收件人与行为在生活中的位置。
- 其他注明‘教学例子／练习’的小例子只阐明关系，不提供诊断证据。

## 学习方法

1. 原话、转述、推论分别记录。归属词帮助辨认主张类型，不提高证据质量。
2. 观察链：语境—当事人言说—回应—后续—未知。该链不构成量表或疗效试验。
3. 研究阅读：对象、干预、对照、主要结局、效应大小、不确定性、时长；同时看其他结果。
4. 提问：已有理解—缺少的连接—一个具体问题。不以公众问答承接个人分析或督导。
5. 会后回看：能否用两句话重述概念、举出关系与例子，并知道什么仍待讨论。

## 阅读主线

基础：身体问题、主体、自我与形象、语言位置、能指、驱力、享乐、症状。
分场：躯体化、青少年、书写、节奏、并入、身体之谜、物与歧义。
进阶：三环及客体小a、圣状、除权、常态精神病的具名文献。
日程、保密、记录与提问工具保留在后段或直接查阅，不以工具卡代替知识。
