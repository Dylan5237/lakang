# 产品要求：刷知识，而不是刷长文章

## 目标

读者在动车上拿起手机即可进入知识卡流；一张卡讲清一个问题，连续阅读逐步建立对大会主题、讲者与日程的理解。使用场景包括首次接触拉康、已有学习基础及临床从业者，不默认所有人具备临床资质。

## P0：一个完整可用的首版

### 1. 知识卡流
- 默认首页就是第一张未读或上次停留的卡，不先要求选择路线、填问卷或阅读说明书。
- 纵向上下滑动逐卡，返回上张不丢位置；桌面有键盘与可见的上一张/下一张按钮。
- 每卡主视图包含主题标签、明确标题、核心解释、一个区别/例子/观察点；在必要时附一条与本届的联系。
- 内容超出主视图时用“展开读”进入详情，避免卡内纵向滚动与整页换卡争夺手势。不能裁掉关键限定，也不能缩小到难读的字号。
- 可收藏、标为读过、随手记；展开详情后返回原卡、原位置。
- 不加入自动翻页、强制倒计时、积分、连续签到或仿造点赞量。借鉴的是低摩擦交互，不是成瘾机制。

### 2. 有组织的内容
- 默认路径有先后关系：大会问题 → 核心概念 → 广州脉络 → 讲者与作品 → 本届议题 → 临床观察与提问。
- 支持按主题、讲者和收藏筛选；有全文搜索与卡片稳定 ID。筛选是辅助，不取代默认连续路径。
- 所有源短章和十位讲者都应被覆盖；保留原文词形和精确阅读入口。
- 不把某讲者当前讲题扩写成其尚未公布的观点或案例。

### 3. 日程
- 保留 `content/agenda.json` 全部区块、标题、讲者、时地与必要注记。
- 按日查看，也能查看五天总览；从场次进入相关卡片，从卡片返回场次。
- 28 日上午：行政楼冼为坚国际会议中心；29 日下午与晚间：会议楼Ⅱ 401 室；其余已列活动：科研楼 Rx104 室。
- 两场开幕演讲共用 28 日 09:30—12:00，不推定分配时间。
- 当前/下一场若实现，固定使用 Asia/Shanghai；会前、会中、会后均有合理状态，不能在大会结束后仍显示已过期的“下一场”。

### 4. 动车与离线
- 核心知识、日程、基本样式和图标本地打包，不依赖远程字体、CDN 或实时内容接口。
- 在线首次加载后提供明确“离线已就绪”状态，并测试断网后冷启动与连续浏览。首次访问就在断网状态不属于可保证场景。
- PWA 可作为实现方式，但不能只注册 Service Worker 就声称离线完成；测试刷新、资源缓存、子路径部署与缓存更新。
- 外部全文链接仍需联网。打不开时不阻断本地卡片；提供题名、作者、章节和链接供稍后查看。
- 收藏、位置与笔记默认仅本机保存；支持导出/导入，导入前校验格式和版本。清空操作须确认，不自动上传。

### 5. 可读性和可访问性
- 手机优先；窄屏、横屏、系统大字和安全区下不遮挡正文与按钮。
- 支持夜读和大字；尊重减少动画设置，不做晕动性翻转。
- 按钮有可读标签，焦点不困在隐藏区域，详情可关闭并归还焦点；手势不是唯一操作方式。
- 页面不默认播放声音，不自动生成音频；首版无需视频或人物照片。

## 内容详情与出处

正文直接讲知识。详情底部用普通书目/来源链接供查阅，不展示“真实性评分”、重复的自证标签或内部核读状态。医学和研究上的必要限制自然写入句子，例如“这项研究纳入 29 名阈下抑郁青少年，观察 6 周”，不要先给一个过大的结论再用一屏免责声明撤回。

## 非目标

不做登录、云端笔记、社交、评论、推荐算法、付费课程、问诊、病例上传、AI 自动分析。没有提出后台 CMS；先让文本/JSON 易编辑即可。不要擅自接入第三方统计或埋点服务。

## 技术自主权

不指定框架、组件树或视觉布局模板。先检查成熟方案，选择能简洁支持移动手势、静态部署、内容维护与离线的组合。旧 HTML 仅提供内容与功能参考，不要求保留原视觉或复制全部遗留脚本。
