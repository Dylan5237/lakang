# 拉康大会 · 随身知识卡

把大会会前准备做成适合动车途中连续阅读的知识卡网站。

## 给接手 Codex 的入口

先读 `docs/CODEX_HANDOFF.md`，再读 `docs/PRODUCT_REQUIREMENTS.md` 与 `docs/EDITORIAL_GUIDE.md`。资料目录和迁移状态见 `docs/MATERIALS_INDEX.md`。

本库的目标不是把长手册缩小放进手机，而是重组为一张一个问题、上下滑动、读完即有所得的知识卡。读者面向所有参会者，不保留私人赠言或称呼。

## 最新确认的产品方向

- 首页直接进入纵向知识卡流；手指上下滑动逐卡阅读，支持返回上一张。
- 重点是扎实的会前知识：广州往届交流脉络、核心概念、十位讲者的工作与作品、本届各场的理解入口。
- 五天日程保留，能从场次进入相关知识卡，也能从卡片返回场次。
- 正文直接讲知识。不要让“来源真实性”“核验边界”“仅为参考”等编辑工作说明占据卡片首屏；出处在详情内可查。
- 不以删去研究条件、理论归属或临床边界来换取流畅。事实与解释的区别写进准确措辞，而不是堆叠免责声明。
- 适合弱网和断网：核心文字预先缓存；阅读位置、收藏和随手记默认仅存本机。

## 资料基线

本届大会：第一届大湾区拉康派精神分析大会，主题《身体如何言说？》，2026 年 10 月 27—31 日，香港中文大学（深圳）。日程使用会议通知中的深圳当地时间（Asia/Shanghai）。

已形成的公共版内容包含：16 个预习短章、10 位讲者导航、13 个术语条目、25 条来源记录，以及五天 15 个日程区块。28 日的两场开幕演讲共用一个时间区块，不自行拆分时间。

当前交接阶段只迁移资料与需求，不声称短视频式网站已经实现或上线。现有公共版 HTML 是上一版阅读手册，不是新交互的验收成品。

## 工作原则

先交付可运行的第一版，不把范围扩展成社区、课程平台、诊疗系统或实时 AI 问答。技术选型由接手开发者结合仓库实际决定，优先成熟组件与静态部署；不要为没有提出的功能增加后端。

真实手机截图与视觉验收由用户提供并与 ChatGPT 核对；本地 Codex 负责实现、程序化测试、构建及日志，不承担基于截图的视觉审查。
