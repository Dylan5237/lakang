# 公共版原件归档

这些是本次对话已经生成或上传的公共版资料，不是新网站的已完成实现。

conference-notice.pdf 是用户上传的原始会议通知；public-handbook-v2.html 是原有单文件阅读手册；public-handbook-v2-release.zip 是原发布包。release-docs 保留包内文档，previous-ui 保留旧公共版页面图；public-handbook-full-text.md 与 embedded-data 是从原 HTML 提取的完整可读文本与嵌入数据。

原件的字节摘要在交接 ZIP 的 MANIFEST.json 中。网站不应把该目录直接全部当作 public 资源。旧私人赠送版不在此目录；所有新前台内容按 docs/EDITORIAL_GUIDE.md 编辑。外部文献只保留书目信息和链接，不附未取得许可的付费全文。
