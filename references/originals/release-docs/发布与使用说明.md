# 身体如何言说？｜大会随身研读手册 · 公共版 2.0

核验与编写日期：2026 年 10 月 26 日。
第一届大湾区拉康派精神分析大会：2026 年 10 月 27—31 日，香港中文大学（深圳）。
这是一份面向所有参会者的非官方学习辅助材料，不是讲稿摘要或诊疗建议。

## 文件与发布

- index.html：唯一必需的发布文件。把它上传到静态网站目录即可，无需安装依赖、打包或配置后端。
- 发布与使用说明.md：本说明。
- 来源与核验清单.md：25 项原始来源、读取范围和限制；便于日后校对。
- 内容目录.md：16 个短章、10 位讲者及相关学习任务的目录。

网页样式、图标、正文和脚本均已内嵌，没有外部字体、CDN、统计或跟踪脚本，也没有上传笔记的接口。推荐通过 HTTPS 发布。页面为 UTF-8，服务器应以 text/html; charset=utf-8 提供。
不要上传个人笔记 JSON 备份、浏览器存储、测试文件或其他私人材料。上面的 index.html 不包含任何个人学习笔记。
原先的私人称呼、赠言与特定关系视角已经移除。

## 怎样使用

“路上读”：选择 15 / 45 / 90 分钟路线，或查看全部 16 个短章；按章展开，可标记已读并继续上次阅读。路线时长只是阅读安排参考，原著全文阅读不计入其中。
“日程”：保留五天正式安排；当前/下一场按深圳当地时间计算，并提示换场。关注、搜索、讲者和预读入口互通。两场开幕演讲仍保持官方公布的合并时间，不虚构各自时段。
“讲者”：10 位讲者的公开工作、可核作品、与本届议题的连接、精确阅读入口和备选问题；完整阅读范围与缺口明确标注。
“工具”：临床演示观察卡、提问卡、13 个术语提示、最小书架、出发检查项和资料来源。
“笔记”：会前、场次、每日小结及会后记录；支持 Markdown 导出、JSON 备份与导入。
顶部支持全文搜索、大字号与夜读。全文搜索不检索私人笔记。
来源编号可点击打开对应说明，再从来源页访问原始网站。

## 路上与离线

短章、讲者档案、日程与工具正文都在单个 HTML 文件内，不需要逐篇联网加载。下载并使用支持本地 HTML 的浏览器打开，正文可离线阅读。
这不是安装式 PWA，没有 service worker；不能保证普通网页关闭后，仅凭曾打开过就一定可以离线重新进入。
外部资料链接仍需要网络，部分书刊可能需要图书馆权限或合法购买。本手册不附付费全文。
iOS“文件”预览、微信内置浏览器可能限制脚本、下载或本地保存。路途中使用前，应在自己的设备上打开并验证导航与记录功能；发布后的 HTTPS 页面通常更适合作为日常入口。

## 笔记、阅读进度与隐私

数据设计为仅保存于当前浏览器的 localStorage，不上传、不公开、不跨设备同步，也未加密。清除浏览器数据、隐私浏览模式、存储被限制、域名或协议改变，都可能使记录不可用或看起来丢失。
浏览器禁止存储时，页面会显示警告；当次输入不应被当作已经永久保存。
定期导出 JSON 备份，并保存在私人位置。Markdown 适合阅读与整理，JSON 适合恢复。
导入支持本版备份和上一版手册的 JSON 备份。导入需要确认；同名笔记将被备份覆盖，其他本地笔记保留；关注和勾选合并。
本版采用新的本地存储名称，不会自动读取上一版个人页面的数据。如要迁移，先在上一版导出 JSON，再在本版“笔记”中导入。
不要录入能够识别个案的资料；不要因“仅在本机”就忽略会务授权、保密规则和共享设备风险。
“打印公共手册”会展开公共章节并默认排除私人笔记。笔记需要通过专门的导出功能另存。

## 内容维护

单文件页面可直接编辑，但日程同时存在于展示卡片和 conference-data 数据段中；更新时必须保持二者一致，避免显示时间与“当前/下一场”计算不一致。
短章或讲者内容修改后，reader-index 搜索索引也需同步。
对外发布时保留来源编号、核验日期、证据范围和未确认事项；不要删去未知信息的限定语后，将阅读建议改写成讲者观点。
